                    HELM INSTALLATION - MANUAL STEPS
================================================================================

All Helm chart files have been created and configured. Follow these commands
to complete the deployment:

================================================================================
STEP 1: UNINSTALL OLD RELEASE (IF EXISTS)
================================================================================

helm uninstall fraud-detection -n default


================================================================================
STEP 2: VALIDATE HELM CHART
================================================================================

cd /home/labuser/IdeaProjects/fraud-detection-service/fraud-detection
helm lint ./helm/fraud-detection-stack/

Expected: "1 chart(s) linted, 0 chart(s) failed"


================================================================================
STEP 3: INSTALL HELM RELEASE
================================================================================

helm install fraud-detection ./helm/fraud-detection-stack/ -n default --create-namespace

OR with explicit wait:

helm install fraud-detection ./helm/fraud-detection-stack/ -n default --create-namespace --wait


================================================================================
STEP 4: VERIFY PODS ARE RUNNING (Wait 20-30 seconds)
================================================================================

kubectl get pods -n default -o wide

  ✓ fraud-detection-* (1/1 Running)
  ✓ prometheus-* (1/1 Running)
  ✓ grafana-* (1/1 Running)
  ✓ mysql-* (1/1 Running)
  ✓ zookeeper-* (1/1 Running)
  ✓ kafka-* (0/1 CrashLoopBackOff - Optional, can be disabled)


================================================================================
STEP 5: VERIFY SERVICES
================================================================================

kubectl get svc -n default -o wide

Expected Services:
  • fraud-detection   ClusterIP
  • prometheus        NodePort (30090)
  • grafana           NodePort (30000)
  • mysql             ClusterIP
  • zookeeper         ClusterIP
  • kafka             ClusterIP


================================================================================
STEP 6: CHECK HELM STATUS
================================================================================

helm status fraud-detection -n default

Should show: STATUS: deployed


================================================================================
STEP 7: PORT FORWARD (OPTIONAL - FOR LOCAL ACCESS)
================================================================================

# Terminal 1: Fraud Detection App

# Terminal 2: Prometheus
kubectl port-forward -n default svc/prometheus 9090:9090

# Terminal 3: Grafana
kubectl port-forward -n default svc/grafana 3000:3000
